## 五、数据源变更记录（2026-11-18）

- 原计划用高德地图 Web 服务 API 替代 Overpass 提速，实测：无 Key 返回 `INVALID_USER_KEY`；且高德 API 只提供
  POI 点位、行政区界 polyline 与路径规划折线，**不提供**全量道路网 / 河湖水系 / 公园林地 / 铁路的矢量几何，
  无法生成 `geo_xa.js`；其 GCJ-02 坐标也与本项目 OSM WGS-84 体系冲突（历史上曾造成数百米至数公里偏差）。
  因此不引入高德，继续用 OSM。
- Overpass 并发（6 块）触发 `429 Too Many Requests`，Geofabrik PBF、OSM 主 API 与备用 Overpass 镜像在本机网络
  直连均超时；仅 `overpass-api.de` 绕过系统代理（`ProxyHandler({})`）可用，间歇性 502 但重试可成功。
- 为缩短抓取时间，范围由「主城区 + 西咸新区 + 咸阳机场」180×176 格缩小为「绕城高速以内」120×120 格，
  分块由 6×6=36 降为 4×4=16。
